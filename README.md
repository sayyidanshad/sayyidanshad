## How I approach building

- Start with a real operational problem and understand the business rules.
- Preserve data accuracy and auditability before visual polish.
- Make complex workflows understandable to the people who use them.
- Use AI-assisted tools to explore ideas, prototype interfaces and improve implementations.
- Treat testing, review and production readiness as separate stages.
